### 🚀 Featured Project

#### 🎭 [Playwright SDET Pro](https://github.com/sarang2199/playwright-sdet-pro)
> End-to-End Automation Framework built with Playwright + JavaScript

**Key Highlights:**
- ✅ Page Object Model (POM) architecture
- ✅ Data-Driven Testing using JSON
- ✅ Reusable utility functions (`CommonUtils`)
- ✅ Screenshot capture on test failure
- ✅ HTML Reports with Playwright Reporter
- ✅ Positive & Negative test scenarios
- ✅ `beforeEach` hooks for test setup

```
📁 Framework Structure
├── tests/          → Test Spec files
├── pages/          → Page Object classes
├── utils/          → Reusable CommonUtils
├── data/           → JSON Test Data
└── playwright.config.ts
```
